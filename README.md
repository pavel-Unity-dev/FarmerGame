# Farmer Game

https://pavel-unity-dev.itch.io/feedthe-herd

Top-down arcade shooter where a farmer feeds hungry animals with pizza 🍕

## 🎮 About the Game

Farmer Game is a simple arcade game with a static top-down camera.

Animals spawn randomly outside the map and move toward the player.  
The farmer must avoid collisions and shoot pizza to feed them.

Each animal has a hunger bar.  
When the hunger bar is fully filled, the animal disappears.

The player earns points for every animal successfully fed.

## 🕹 Gameplay Features

- Static top-down camera
- Random enemy (animal) spawning outside the map
- Movement toward player
- Pizza shooting mechanic
- Hunger bar system for each animal
- Score system displayed on screen
- Basic dodge mechanic
- Endless survival style gameplay

## 🛠 Built With

- Unity
- C#
- Object-oriented scripting
- Basic AI movement logic
- UI system (score & hunger bars)

## 📈 Game Loop

1. Animals spawn outside the map
2. Animals move toward the farmer
3. Player shoots pizza to feed them
4. Hunger bar fills up
5. Animal disappears
6. Player gains score
7. Repeat
